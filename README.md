# Diseño y prueba de concepto de un sistema de super-resolución satelital mediante Swin Transformers y Redes Adversarias

Las imágenes satelitales de alta resolución son herramientas fundamentales en áreas como el urbanismo o la agricultura. Pero su obtención tiene un coste muy elevado. A su vez, las fotografías de libre acceso suelen tener una resolución demasiado baja para ciertos análisis. Este Trabajo Fin de Grado explora cómo la Inteligencia Artificial puede resolver este problema mediante técnicas de "super-resolución", capaces de mejorar digitalmente la nitidez y el detalle de estas capturas.
El proyecto se plantea como una prueba de concepto tecnológica. Para ello, se ha desarrollado un sistema completo que simula las limitaciones físicas de los satélites en el espacio. Además, se ha automatizado la obtención de datos y procesamiento de los mismos. Sobre este escenario, se han implementado arquitecturas de Inteligencia Artificial de libre acceso. También se han diseñado estrategias para superar las fuertes restricciones técnicas y de memoria que exigen estos procesos.
Durante la fase de experimentación, se ponen a prueba y se comparan diferentes enfoques de entrenamiento: uno centrado en la exactitud matemática de la imagen (PSNR), y otro en la recreación visual de texturas complejas como carreteras o vegetación (GAN). El objetivo final es evaluar la viabilidad de estas arquitecturas sobre capturas satelitales y sentar unas bases sólidas que permitan, en el futuro, aplicar este mismo sistema para igualar la calidad de los sensores comerciales privados partiendo de las imágenes públicas de Sentinel.
